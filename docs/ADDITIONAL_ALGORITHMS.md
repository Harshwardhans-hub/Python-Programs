# Additional Algorithm Examples

| Module | Focus |
| --- | --- |
| `array_algorithms.py` | Kadane's maximum-subarray scan, products excluding self, stable zero movement |
| `string_search.py` | KMP matching with overlapping occurrences |
| `graph_advanced.py` | Topological ordering and unweighted shortest paths |
| `tree_algorithms.py` | Symmetry, balance, and diameter |
| `geometry_utils.py` | Euclidean and Manhattan distances, rectangle containment |
| `pathfinding.py` | Shortest 4-directional path through a blocked grid |
| `sequence_algorithms.py` | Consecutive runs, majority element, one-transaction stock profit |

Each module is independent of external packages and has a matching test file. Run the complete suite with:

```bash
python -m unittest discover -s tests -v
```
