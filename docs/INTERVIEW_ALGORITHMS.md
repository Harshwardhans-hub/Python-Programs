# Interview Algorithm Practice

This set adds several reusable patterns beyond the core data-structure examples.

| Module | Pattern | Examples |
| --- | --- | --- |
| `prefix_sums.py` | Precomputation | Inclusive range-sum queries |
| `stack_algorithms.py` | Monotonic and validation stacks | Balanced brackets, next greater element |
| `queue_algorithms.py` | Monotonic deque | Sliding-window maximum |
| `string_dp.py` | Dynamic programming | LCS, edit distance, palindromic subsequence |
| `math_algorithms.py` | Number theory | Prime sieve, factorization, modular power |
| `lru_cache.py` | Cache eviction policy | Least-recently-used key eviction |
| `binary_search_tree.py` | Ordered tree operations | Insert, search, delete, inorder traversal |

All examples are dependency-free and tested. Run:

```bash
python -m unittest discover -s tests -v
```
